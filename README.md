# 投资导航 · INVEST NAV

独立的中文投资资源导航，包含 **美股投资、加密货币、投资工具** 三大栏目。

纯 HTML / CSS / JavaScript，无框架、无安装步骤、无后端、无 API 密钥。不调用 invest-nav.com 的接口，不复用其文章、图片或品牌素材。27 个资源的文字、网址和标记全部保存在本地，页面无需远程字体或图标。

## 使用

直接打开 `index.html`，或者在项目目录运行：

```sh
python3 -m http.server 5173
```

访问 http://localhost:5173 。任何静态托管服务均可部署本目录。GitHub Pages 选择 `main` 分支根目录；Vercel / Netlify 使用静态站点，无需构建，发布目录为项目根目录。

## 功能

- 分类、二级筛选、名称及关键词搜索，多关键词匹配
- 精选优先与名称排序
- 深浅主题，初次跟随系统，此后记住手动选择
- 手机导航、响应式布局、键盘 `/` 聚焦搜索、Escape 收起导航
- 美股页面显示标普 500 / 纳斯达克 100 指数的腾讯财经行情；可能延迟，休市时显示最近可用行情，加载异常可使用外链或刷新重试
- 交易平台中 Coinbase 固定在最后，包含欧易 OKX；新增 Solana 与 OKLink
- 资源卡片在新窗口打开第三方官网

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面语义结构 |
| `styles.css` | 响应式样式、深浅主题及 CSS 指南针插画 |
| `data.js` | 导航资源数据 |
| `app.js` | 搜索、筛选与主题交互 |
| `favicon.svg` | 本地站点图标 |

编辑 `data.js` 可维护资源。每一行依次是唯一 ID、名称、简介、HTTPS 网址、栏目（stocks / crypto / tools）、分组、图标文字、图标背景色、关键词、是否精选。

主题保存在浏览器 localStorage，不会上传到服务器，无法跨浏览器同步。存储不可用时仍可使用本次会话的主题。外部服务可能需要注册、付费或特定地区访问条件，导航不保证第三方服务可用性，也不代表投资推荐。

## 验证

```sh
node --check app.js
node --check data.js
```

浏览器中检查搜索、分类筛选、主题切换和移动端布局。

指数区仅在美股页面加载腾讯财经公开行情脚本，每 60 秒刷新，显示点位、涨跌额、涨跌幅及数据时间，不需要后端或 API 密钥，不调用参考站接口。离线或第三方不可用时导航仍可使用，指数行情不可用。

美股指数卡片提供最近一年的日 K 线（腾讯财经历史 OHLC 数据），支持鼠标悬停或键盘左右键查看开高低收。SVG 由本地 `kline.js` 绘制，无图表库依赖；历史行情失败时展示错误并支持刷新。Binance 与 OKX 使用官网提供的品牌图标，保存在 `assets/`。


## Cloudflare Pages 自动部署

在 Cloudflare 控制台的 Workers & Pages 中创建 **Pages** 项目，导入 `dark8ranger/invest` 仓库：

| 设置 | 值 |
| --- | --- |
| 框架预设 | None |
| 生产分支 | `main` |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 根目录 | 留空（仓库根目录） |
| 环境变量 / API 密钥 | 不需要 |

部署完成后会获得 Cloudflare 分配的 `*.pages.dev` 地址。此后推送 `main` 自动触发生产部署。该方案使用 Pages 原生 GitHub 集成，无需在仓库或 GitHub Actions 中保存 Cloudflare Token。

本地验证发布文件：

```sh
npm run check
npm run build
```

`dist/` 仅包含站点文件与图标，不发布 Git 目录、文档或其他本地文件。行情与历史 K 线由访问者浏览器直接请求腾讯财经，不依赖 Cloudflare 后端。
