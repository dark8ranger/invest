# 投资导航 · INVEST NAV

独立的中文投资资源导航，包含 **美股投资、加密货币、投资工具** 三大栏目。

纯 HTML / CSS / JavaScript，无框架、无安装步骤、无后端、无 API 密钥。不调用 invest-nav.com 的接口，不复用其文章、图片或品牌素材。24 个资源的文字、网址和标记全部保存在本地，页面无需远程字体或图标。

## 使用

直接打开 `index.html`，或者在项目目录运行：

```sh
python3 -m http.server 5173
```

访问 http://localhost:5173 。任何静态托管服务均可部署本目录。GitHub Pages 选择 `main` 分支根目录；Vercel / Netlify 使用静态站点，无需构建，发布目录为项目根目录。

## 功能

- 分类、二级筛选、名称及关键词搜索，多关键词匹配
- 精选优先与名称排序
- 本地收藏、收藏列表，刷新后保留
- 深浅主题，初次跟随系统，此后记住手动选择
- 手机导航、响应式布局、键盘 `/` 聚焦搜索、Escape 收起导航
- 无模拟行情或实时资讯；资源卡片在新窗口打开第三方官网

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面语义结构 |
| `styles.css` | 响应式样式、深浅主题及 CSS 指南针插画 |
| `data.js` | 导航资源数据 |
| `app.js` | 搜索、筛选、收藏与主题交互 |
| `favicon.svg` | 本地站点图标 |

编辑 `data.js` 可维护资源。每一行依次是唯一 ID、名称、简介、HTTPS 网址、栏目（stocks / crypto / tools）、分组、图标文字、图标背景色、关键词、是否精选。

收藏和主题保存在浏览器 localStorage，不会上传到服务器，无法跨浏览器同步。存储不可用时仍可使用本次会话的收藏和主题。外部服务可能需要注册、付费或特定地区访问条件，导航不保证第三方服务可用性，也不代表投资推荐。

## 验证

```sh
node --check app.js
node --check data.js
```

浏览器中检查搜索、分类筛选、收藏及刷新保留、主题切换和移动端布局。
